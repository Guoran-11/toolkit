## 0. 硬约束（所有人都必须遵守）

1. **不引入新的第三方运行时依赖**。现有 venv 只有 fastapi / uvicorn / pydantic / pypdf / openpyxl 等核心包；`httpx` 仅测试用（已装），生产代码不得 import 它。HTTP 一律用标准库 `urllib.request`（见 §5.2）。

3. 响应字段 **snake_case**；查询参数兼容前端 camelCase（`pageSize`）与 snake_case。
4. 错误体统一 `{"detail": "<中文>", "code": "<机器码>"}`，用 `app/core/errors.py` 的异常子类；禁止裸 500 与「未知错误」。
5. 时间字符串统一 `app.core.tasks.utc_now_iso()`（毫秒 + `Z`）。
6. **文件写入范围**：每位成员只改自己任务里列出的文件。共享文件（`app/core/*`、`app/main.py`、`config.toml`）由 Lead 独占。

   `.\.venv\Scripts\python.exe .piptmp\run_pytest.py -q --basetemp=.piptemp\pt`
   测试代码本身**不要**为此做任何兼容处理（正常用 `tmp_path` 即可）。
8. 不要改 `.piptmp/`、`storage/`、`.verify/`、`docs/视频下载模块-PRD-v1.0.*`（PRD 原文只读）。

### 3.2 `POST /api/video/parse`
请求：
```json
{"urls": ["7.43 复制打开抖音… https://v.douyin.com/xxx/", "https://www.bilibili.com/video/BV1xx411c7mD"],
 "prefer_quality": "1080P"}
```
- `urls` 长度 1..20（超限 400 `VALIDATION_ERROR`，文案「单次最多解析 20 条链接」）。
- 从每条原始文本里提取链接（正则 `https?://[^\s"'<>（）()，。！？【】]+`，去尾部中文标点），同一批按 URL 去重。
- 响应 200，**逐条返回**，单条失败不影响整批；`elapsed_ms` 为总耗时：
```json
{"results": [
  {"ok": true, "url": "https://www.douyin.com/video/7412345678901234567",
   "cached": false,
   "item": {"platform": "douyin", "item_id": "...", "url": "...", "media_type": "video",
            "title": "晚风里的一百种蓝", "description": "",
            "author": {"name": "某某", "id": "MS4wLj...", "avatar_url": "https://..."},
            "cover_url": "https://...", "duration_sec": 151,
            "published_at": "2026-10-12T09:30:00.000Z", "stats": {"like": 1, "comment": 2, "share": 3, "play": 4},
            "formats": [{"format_id": "v-1080", "quality": "1080P", "width": 1920, "height": 1080,
                         "fps": 30, "bitrate": 2500000, "container": "mp4", "size_bytes": 47187500,
                         "need_login": false, "need_vip": false, "expire_at": null, "note": null,
                         "available": true}],
            "default_format_id": "v-1080",
            "images": [], "piece_count": 1, "warnings": [], "parse_source": "api"}},
  {"ok": false, "url": "https://www.bilibili.com/video/BV1xx411c7mD",
   "error": {"code": "LOGIN_REQUIRED", "detail": "该清晰度需要登录，当前仅可下载 720P"},
   "item": {"platform": "bilibili", "item_id": "BV1xx411c7mD", "media_type": "video",
            "title": "示例稿件",
            "formats": [{"format_id": "80", "quality": "1080P", "need_login": true, "available": false},
                        {"format_id": "dash-64-7", "quality": "720P", "need_login": false, "available": true}],
            "default_format_id": "dash-64-7",
            "warnings": ["LOGIN_REQUIRED"]}}
], "elapsed_ms": 1284}
```
- 部分成功语义：`ok=false` 且带 `item` 时前端仍可降级下载（`LOGIN_REQUIRED` / `COOKIE_INVALID` 典型）。
- **`formats[].available`（bool）**：该清晰度是否真的拿到了媒体地址。`false` 表示平台只返回了档位、
  没有给流地址的「占位项」——前端必须置灰且不得默认选中；下载接口对占位项返回明确错误，
  不会误报 `LOGIN_REQUIRED`。
- **`item.default_format_id`（string|null）**：后端推荐的默认可下载 `format_id`，保证
  `available=true`（无可用项时为 `null`）。前端优先采用它，再退回本地策略。
- **`format_id` 约定**：必须**跨两次解析稳定**（下载任务会重新解析后按 id 回查），同一响应内应唯一。
  B站 DASH 为 `dash-{qn}-{codecid}`（同一 qn 的多编码只保留 AVC 一条）、渐进式为
  `durl-{qn}`、无地址占位项为 `{qn}`；其它平台沿用各自平台标识。

### 3.3 `POST /api/video/download`
请求：
```json
{"items": [{"url": "https://www.douyin.com/video/741...", "platform": "douyin",
            "item_id": "741...", "format_id": "v-1080", "output": "mp4",
            "title": "晚风里的一百种蓝", "author": "某某", "quality": "1080P"}]}
```
- `output`: `mp4` | `mp3` | `m4a`（图文作品忽略，固定 zip）。
- 响应：任务数组（每项 = `TaskRecord.to_api()`），字段与 `mock.createTask` 完全一致：
  `task_id/module/operation/status/progress/inputs/output/error/error_code/created_at/started_at/finished_at/expire_at`。
- `module="video"`, `operation="download"`, `inputs=[{"name": title, "size": 0, "sha256": "", "source": url}]`。
- 提交前检查磁盘（`min_free_gb`）→ 不足 507 `DISK_FULL`；平台熔断中 → 429 `RISK_CONTROL`；超限流 → 429 `RATE_LIMITED`（带 `retry_after`）。
- 命中去重（24h 内同 `platform+item_id` 且产物未过期）→ 新建任务并**立即 success**（复用 `file_id`），`inputs[].source` 保留，前端提示「已为你复用」。
- `GET /api/tasks?module=video` 可查到这些任务。

### 3.4 `GET /api/video/history`
查询：`platform`（可选）、`keyword`（标题搜索，可选）、`page`（默认 1）、`pageSize`（默认 20，最大 100）。
```json
{"total": 42, "page": 1, "page_size": 20,
 "items": [{"platform": "douyin", "item_id": "...", "title": "...", "author": "某某",
            "cover_url": "https://...", "quality": "1080P", "size_bytes": 47187500,
            "status": "success", "task_id": "...", "file_id": "f_8a3c2e",
            "created_at": "2026-10-20T13:10:13.123Z", "expire_at": "2026-10-21T13:10:13.123Z"}]}
```
- 只保留 `url`（长链）与 `file_id`，**绝不保存**媒体直链。
- `DELETE /api/video/history/{item_id}?platform=douyin` → `{"ok": true, "removed": 1}`
- `DELETE /api/video/history` → `{"ok": true, "removed": N}`（不删产物，只清历史；产物按 TTL 自动回收）

## 4. 后端模块结构（backend-video 独占 `app/modules/video/**`）

├─ router.py            # 只做协议转换（Pydantic 校验 + 调 service），不写业务

├─ net.py               # 标准库 HTTP：get_text / get_json / head / 流式 Range 下载 + SSRF 校验
├─ cache.py             # 解析结果内存缓存（TTL + 容量上限）
├─ history.py           # storage/video_history.json 原子读写、去重、筛选、分页

├─ downloader.py        # 分片下载 / 断点续传 / 进度映射 / FFmpeg 合并 / 转 mp3 / 图文 zip
├─ maintenance.py       # sweep()：过期历史、残留 storage/temp/video-*
└─ adapters/
   ├─ __init__.py
   ├─ base.py           # PlatformAdapter 协议 + ParseContext + 清晰度归一化
   ├─ registry.py       # 域名白名单 + 平台注册 + 短链展开（每跳校验）+ SSRF 判定
   ├─ douyin.py

   ├─ kuaishou.py

分层纪律：`adapters/*` 只做「链接 → 元数据 / 媒体地址」，不碰任务、不落盘；`router` 无业务逻辑；`service` 负责错误码映射与任务编排。

### 4.1 解析降级链
平台公开接口/页面 JSON → 分享页 HTML（`__INITIAL_STATE__` / `RENDER_DATA` / og:*）→ yt-dlp（可选）→ 明确错误码。
- 每级失败**不要**立即抛错，先尝试下一级；最终按最具体的错误码返回（`ITEM_NOT_FOUND` > `LOGIN_REQUIRED` > `PARSE_FAILED`）。
- B站未配置 Cookie 时：`playurl` 用 qn=64/默认，返回的最高清晰度即匿名最高；若 1080P 需登录，在 `formats` 里标记 `need_login=true` 并附 `warnings:["LOGIN_REQUIRED"]`，`ok=false` 但带 `item`。
- **抖音（2026-10 平台改版）**：`https://www.iesdouyin.com/share/video/{id}/` 对普通 UA 已不再内嵌
  作品 JSON（`videoInfoRes` 缺失）；适配器在首次解析失败时会向平台公开注册接口申请**匿名访客
  Cookie `ttwid`**（进程内缓存 6h）后重抓一次。该 Cookie 不代表登录态、不涉及付费内容或签名伪造；
  用户配置的登录 Cookie 仍原样透传、不读取不记录。
- 平台 API 变更时只改对应 adapter 文件。

### 4.2 清晰度归一化（`adapters/base.py`）
按高度：≥2160→4K；≥1440→2K；=1080 且 fps≥50→1080P60；=1080→1080P；=720→720P；=540→540P；=480→480P；<480→360P；无视频轨→audio。
默认选择：用户 `prefer_quality` 可用则用；否则取 ≤1080P 的最高可用；**绝不默认 4K**。

### 4.3 下载（`downloader.py`）
- 先用 `HEAD`/`Range: bytes=0-0` 取 `Content-Length` 与 `Accept-Ranges`；无 Range 支持则退化为单流。
- 分片大小 `segment_size_mb`，单任务并发 `download_segments`，每片重试 3 次（0.5/1/2s 退避），任务级重试 2 次。
- 进度：1–5 准备、5–15 连接、15–90 下载、90–98 合并封装、98–100 登记；用 `ctx.progress()`（自身单调）。
- 取消：每片检查 `ctx.cancelled`，清理临时目录后抛 `TaskCancelled`。
- 超时 `timeout_sec=video.task_timeout_sec_video`；单文件超 `max_file_mb` → `OutputTooLargeError`；磁盘不足 → `DiskFullError`。
- DASH 分离音视频 → `core.engines.ffmpeg_path()` 合并（`-c copy`）；缺 FFmpeg → `EngineUnavailableError` + 安装指引。仅音频 mp3 用 `-vn -c:a libmp3lame -b:a 128k`；m4a 直通音轨。
- 图文作品：图片下载后 zip 打包（按 `01.jpg` 顺序）。
- 产物：`stage_output()` → `JobResult`；命名用 `naming.build_name()`。

### 4.4 断点续传
临时目录 `storage/temp/video-<task_id>/`；分片文件 `seg-0001.part` + `meta.json`（总大小、URL、片段表）。重试时若分片完整则跳过；服务重启后目录保留 24h，`maintenance.sweep()` 清理更早的。无法续传则从头下载。

### 4.5 命名规则
`{platform}-{author}-{title}-{quality}.{ext}`；清洗 `\ / : * ? " < > |` 与控制字符、压缩空白、总长 ≤120 字符；空作者 `未知作者`，空标题 `未命名作品`；同名追加 `-1`、`-2`（按 registry 中未过期同名产物判断）。

### 4.6 限流 / 熔断 / 审计
- 解析：20 次/分钟、100 次/小时；下载：10 次/分钟、50 次/小时（按 `ip + user` 维度）。超限 `RateLimitedError` + `extra={"retry_after": n}`。
- 熔断：同平台连续 5 次 `RISK_CONTROL`/`PARSE_FAILED` → 冷却 10 分钟，期间提交/解析立即 `RiskControlError`（带 `retry_after`）。
- 审计：`write_audit_log({"action":"video.download","ip":...,"platform":...,"item_id":sha256 前 8 位,"quality":...,"size":...,"result":...,"error_code":...})`；不记完整 URL 与 Cookie。

### 4.7 模块关闭
所有端点先经依赖 `require_video_enabled`（读 `settings.video.enabled`），关闭时抛 `ServiceDisabledError`（503 `SERVICE_DISABLED`）。

## 5. 关键实现约定

### 5.1 `models.py` 的 `to_api()`
严格输出 §3.2 的 item 字段；`formats[]` 字段齐全（缺省用 `None`/`false`，另加 `available`）；
`images=[]`、`warnings=[]` 恒存在；`default_format_id` 由 `service._parse_one()` 写入（保证指向
`available=true` 的格式，无可用项为 `null`）。

### 5.2 `net.py`（标准库 HTTP）
- `http_get_text(url, *, timeout=5, headers=None, max_redirects=5) -> (final_url, text, status)`：**手动**跟随重定向，每跳回调校验（`registry.validate_hop`）；仅 https；拒绝 `file/ftp/data` 等 scheme。
- `http_get_json(...)`、`http_head(url, ...) -> (status, headers)`。
- `http_post_json(url, *, json_body=None, timeout=5, headers=None, max_redirects=3, validator=None) -> (final_url, payload, status, headers)`：与 GET 同样的**逐跳 SSRF 校验**（默认 `validate_public_url`，公网即可）；返回小写键响应头，供抖音申请匿名访客 Cookie 时读取 `Set-Cookie`。
- 下载：`open_stream(url, range_start, range_end, timeout)` 返回可读流。
- UA 固定（可被 config 覆盖留 P2）；`Accept-Encoding: identity`（避免 gzip 干扰 Range）。
- SSRF：`registry.validate_public_url(url)` —— scheme=https、host 非字面内网/回环/链路本地/元数据地址（`ipaddress` 判定）、DNS 解析结果全部为公网地址（解析失败时：白名单平台域名放行、其余拒绝）。

### 5.3 `history.py`
`storage/video_history.json`，结构 `{"items": [ ... ]}`，`os.replace` 原子写；上限 `history_limit`（默认 200，FIFO 淘汰）；`dedupe()` 返回 24h 内可复用记录；线程安全（`threading.RLock`）。

### 5.4 `credentials.py`
- 落盘 `storage/credentials.json`，结构 `{"version":1,"items":{"bilibili":{"nonce":"...","ciphertext":"...","tag":"...","updated_at":"..."}}}`，权限 0600。
- 密钥：`app.core.security.secret_store.secret` 经 HMAC 派生。
- 优先 `cryptography` 的 `AESGCM`；`ImportError` 时回退到 HMAC-SHA256 计数器模式流加密 + HMAC 校验（同一模块内 `_seal/_unseal`，docstring 说明这是无第三方依赖的降级实现）。
- 脱敏：B站 `SESSDATA=****9f2a`；抖音/快手取 `key=value` 的前 4 个键名 + 末 4 位，无 `=` 时 `****{后4位}`。
- 禁止明文日志。

### 5.5 设置写回 config.toml
逐行替换 `[video]` 段内已有键，缺失则追加到段尾；不要用 toml 序列化重写整文件（会丢注释）。若文件只读，内存生效并记 warning。
